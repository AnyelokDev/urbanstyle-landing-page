# UrbanStyle - Página de Comercio Electrónico

Este repositorio contiene una página web diseñada para la marca de ropa **UrbanStyle**. Fue desarrollado como parte de la materia de **Producción de Textos e Hipertextos** dentro del programa de **Técnico en Servicios de Seguridad Informática**.

## ¿Qué tiene el proyecto?
* **Diseño responsivo**: La página se adapta a dispositivos móviles y pantallas de escritorio usando clases de utilidad de Tailwind CSS.
* **Identidad visual**: Diseñado con un tema oscuro y acentos neón, utilizando fuentes integradas desde Google Fonts.
* **Función de exportación**: Incluye una opción configurada para que la vista de la página se pueda imprimir directamente a formato PDF de forma ordenada.

## Archivos del repositorio
* `index.html`: Estructura HTML de la landing page.
* `css/style.css`: Estilos de diseno de la pagina (estetica neon/oscura y adaptacion de impresion a PDF).
* `js/app.js`: Funcionalidad interactiva y exportacion a PDF.
